API Documentation

            
Integrate DocuSense programmatically into Python, Node.js, or cURL workflows.

          

          
             OpenAPI / Swagger Docs
          
        


        

          
          

            POST
            /api/parse-pdf
          


          
          

            
cURL Example

            
curl -X POST "http://localhost:8000/api/parse-pdf" \
  -H "Content-Type: application/json" \
  -d '{
    "pdf_url": "https://example.com/sample.pdf",
    "process_sequentially": true
  }'


            
Python Example

            
import requests

response = requests.post(
    "http://localhost:8000/api/parse-pdf",
    json={
        "pdf_url": "https://example.com/sample.pdf",
        "process_sequentially": True
    }
)
result = response.json()
print("Summary:", result["data"]["summary"])
print("Parsed Text:", result["data"]["text"])
